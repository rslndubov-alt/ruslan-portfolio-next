# 🤖 Job Hunter Bot — Автономный поиск вакансий

## Идея
Скрипт-робот, который **каждые 6 часов** сканирует сайты вакансий, находит подходящие под твой стек, 
и отправляет топ-матчи тебе в **Telegram**.

## 🔍 Источники вакансий (бесплатные API)

| API | Что ищет | Бесплатно | Remote |
|---|---|---|---|
| **Remotive** | Remote-вакансии в IT/AI | ✅ Полностью | ✅ Только remote |
| **Arbeitnow** | Европейские вакансии | ✅ Полностью | ✅ Фильтр |
| **Adzuna** | Глобальный агрегатор | ✅ 250 запросов/мес | ✅ Фильтр |
| **The Muse** | Компании + вакансии | ✅ Полностью | ✅ Фильтр |
| **JSearch (RapidAPI)** | Google Jobs агрегатор | ✅ 200 запросов/мес | ✅ Фильтр |
| **Freelancer/Upwork** | Фриланс-проекты | ⚠️ Нужен OAuth | ✅ Всё remote |

## 🧠 Gemini Matcher — Система скоринга

Gemini получает описание вакансии и оценивает совпадение:

```
Твой стек: ChatGPT, Midjourney, Claude, Suno, Google AI, 
           Veo, Seedance, Prompt Engineering, CapCut, 
           Photoshop, Illustrator, Next.js

Критерии скоринга:
┌─────────────────────────┬────────┐
│ Совпадение инструментов │ 0-30   │
│ Remote / гибкий график  │ 0-20   │
│ Уровень оплаты          │ 0-20   │
│ Тип работы (creative)   │ 0-15   │
│ Длительность проекта    │ 0-15   │
└─────────────────────────┴────────┘
Итого: 0-100

Порог отправки в Telegram: ≥ 60
```

## 🗄️ Хранение (не показывать одну вакансию дважды)

Supabase таблица `job_matches`:

| Колонка | Тип | Описание |
|---|---|---|
| `id` | uuid | PK |
| `source` | text | "remotive" / "adzuna" / ... |
| `external_id` | text | ID вакансии на источнике |
| `title` | text | Название |
| `company` | text | Компания |
| `url` | text | Ссылка |
| `score` | int | Скор Gemini (0-100) |
| `summary` | text | Краткое описание от Gemini |
| `sent_at` | timestamp | Когда отправлено в TG |
| `created_at` | timestamp | Когда найдено |
